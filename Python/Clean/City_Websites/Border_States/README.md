# Border-State Website Analysis Data

Run `create_border_state_website_analysis_data.py` to rebuild border-state website intermediates from existing website collection inputs.

Outputs:

- `Data/Clean_Intermediate/Websites/border_state_website_data_with_recovered.csv`
- `Data/Clean_Intermediate/Websites/missing_url_year_pairs.csv`

This script does not perform website scraping.
