# Texas Website Analysis Data

Run `create_texas_website_analysis_data.py` to rebuild Texas website intermediates from existing website collection and election inputs.

Outputs:

- `Data/Clean_Intermediate/Websites/Texas/time_series_website_data.csv`
- `Data/Clean_Intermediate/Websites/Texas/election_level_website_data.csv`

This script does not perform website scraping.
